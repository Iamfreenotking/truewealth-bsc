04 · 清楚回答

重要问题

信息越透明，越容易做出自己的判断。

这是 CZ 或 Binance 的官方代币吗？

不是。CZ 的帖子只是名称和概念的灵感来源。TRUEWEALTH 与 CZ、Binance、BNB Chain、PancakeSwap、OKX 或 Phantom 没有官方合作或背书。

为什么钱包里看不到 525 万枚团队份额？

因为这些代币在独立团队保管合约中，不直接显示在受益人的普通钱包余额里。受益人可以取出；它不是锁仓。

LP 销毁代表绝对安全吗？

不代表。它只表示对应凭证被发送到无法控制的地址，不等于价格稳定、没有风险或一定能卖出。

这里会要求连接钱包吗？

不会。网站只展示资料并链接到公开区块浏览器和 PancakeSwap。所有钱包确认都必须由用户本人阅读并决定。
