# Security policy

This repository documents an immutable mainnet token. The deployed contracts cannot be upgraded or paused. Do not open a public issue containing seed phrases, private keys, wallet recovery words, API keys, or exploitable account details.

For suspected issues, first preserve evidence and avoid sending transactions until you understand the risk. Report privately through GitHub's private vulnerability reporting feature if enabled for this repository. No independent audit or bug bounty is claimed.

Official contract identity is the full address `0x962C4730CFd8478D63C754c6060B82Aa2142d8D1` on BNB Smart Chain mainnet (chain ID 56). Similar names and tickers are not proof of identity.
